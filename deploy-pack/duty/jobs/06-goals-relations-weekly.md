# Job 06 · 目标/关系/对齐周复盘（goals-relations-weekly）

- **用途**：方案 D5 自我改进回路的周频部分。框架没有 Muse 的目标对象与对齐合成，用文件约定近似：目标档案在 `$HERMES_HOME/goals/`（一目标一文件），人物档案在 `memories/people/`，对齐校准产出 `$HERMES_HOME/ALIGNMENT.md`，供日常会话参考。
- **调度**：每周日 20:00：`0 20 * * 0`（在晚报之前跑，结论可被当晚晚报引用）。
- **登记命令**：

```bash
hermes cron create "0 20 * * 0" "<见下方提示词全文>" \
  --name goals-relations-weekly --deliver origin --skill duty-officer
```

- **验收点**：`goals/` 为空时手动触发，输出应是「暂无目标档案」并给出建档格式说明，不许虚构目标；建一个测试目标文件后再触发，周报里应包含该目标的进展条目；`ALIGNMENT.md` 被创建或更新且含日期戳。

## 提示词全文

你做每周复盘，三件事：目标、关系、对齐。步骤：

1. 目标：用 `search_files` 列 `$HERMES_HOME/goals/` 下的 .md 文件。为空则输出「暂无目标档案」并附建档格式（一文件一目标：目标、为什么、当前进展、下一步、停止条件），跳到第 3 步。非空时逐个 `read_file`，对照本周会话与值班台账，逐目标写：本周进展（只写有证据的）、卡点、下一步建议。没有新进展就直说「本周无进展」，不许编造。
2. 关系：用 `search_files` 列 `memories/people/`，找出超 90 天未更新的档案页，列入周报「关系保鲜」区，逐页一句：此人是谁、最后一次互动是什么时候（以档案内记录为准，取不到就写取不到）。不要在本 job 里改动 people 档案内容——那是日常当场记与用户确认的事。
3. 对齐：综合本周晚报、记忆变更摘要与台账销项，更新 `$HERMES_HOME/ALIGNMENT.md`（不存在则新建）：只写「怎么对用户」的校准结论——沟通偏好变化、被纠正过的判断、反复出现的雷区、本周验证有效的做法。每条带日期与一句依据；与旧条冲突时新替旧并注明，不许新旧并存。本文件是给未来的你看的，写断言不写感想。
4. 输出周报：目标进展、关系保鲜清单、对齐变更摘要（改了哪几条），每段没有内容就写「无」，不许凑数。
