# Job 03 · 晚间汇总（evening-digest）

- **用途**：把当天攒下的备稿、待核实项、值班系统自身状态合成一份晚报，一次投递，避免全天碎片打扰。
- **调度**：每日 21:30：`30 21 * * *`（部署者按自己作息改时间，注意避开 PREFERENCES 的安静时段起点）。
- **登记命令**：

```bash
hermes cron create "30 21 * * *" "<见下方提示词全文>" \
  --name evening-digest --deliver origin --skill duty-officer
```

- **验收点**：当天 drafts 里有攒晚报标记的条目时，手动触发后收到一份晚报且条目齐全；当天无任何攒项时，晚报只含「值班状态」一段或按提示词约定不发（见提示词第 5 条，二选一在部署时定死，不要两可）。

## 提示词全文

你值晚班，负责合成今日晚报。步骤：

1. 用 `read_file` 读 `$HERMES_HOME/duty/drafts/` 当日全部备稿，挑出标注「攒晚报」与「待核实」的条目；再读 WATCHLIST.md 确认每条对应的事项仍在册。
2. 逐条复核：攒下之后情况又变了的，以最新状态为准并注明；已失效的直接剔除并在 drafts 里补归档原因。
3. 晚报结构（Markdown）：
   - `## 今日需要你决策的`（待决策类，没有写「无」）
   - `## 状态变化`（已变类，逐条带出处）
   - `## 待核实（单源，未证实）`（明确标注未证实，不许写成事实）
   - `## 值班状态`（今日各值班 job 是否正常：用 `hermes cron runs` 与 `hermes cron incidents` 经 `terminal` 核对，只报异常与一句总评）
4. 全文不超过一屏半；长证据给文件路径不贴全文。
5. 当天四段全空（无攒项、无异常）时不发晚报（输出空）。部署者若选择「空也要发一句平安」，把本条改为固定发「今日无事，值班正常」一行——部署时二选一并删掉另一句。
6. 发出后把当日 drafts 文件头标注 `<!-- digested: 日期 -->`，防次日重复汇总。
